# AI-POWERED CRYPTO TRADING PLATFORM
Developed a full-stack application using Spring Boot, React, and
MongoDB with an AI chatbot integrated via Gemini API and CoinGecko API for real-time crypto data. Implemented secure
buy/sell transactions, portfolio tracking, and wallet features including transfers and withdrawals. Integrated Spring Security
with 2FA and Razorpay/Stripe for secure authentication and payments.
